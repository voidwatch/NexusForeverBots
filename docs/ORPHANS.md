## Reading this

- Worlds: the 1811 unreferenced are mostly test maps, PvP/housing plug variants and unused art worlds (names such as Map\\RyanTest3). The playable worlds and instances are all referenced.
- Quests: the unreachable ones are almost all blank-title rows (no text exists), so they cannot have been shipped. See docs/quest-gaps.tsv for the quests that do have text and a giver but no spawn.
- Spells and items: the generic scan only sees table references. Level-based generated loot and spells cast through class/AMP tables with other field names can still reach some of them, so treat these two lists as candidates to inspect, not as dead data.
